# INSPIRASI DESAIN NAVIGASI SIDEBAR GENTRA
> Dokumentasi & Referensi Arsitektur UI: Navigasi Sidebar Responsif (Dark/Light) agar tata letak tidak selalu menumpuk di atas.

## 📌 Sumber Inspirasi Utama
1. **React Sidebar Projects Showcase**  
   - URL: [https://react-sidebar.vercel.app/projects](https://react-sidebar.vercel.app/projects)  
   - Karakteristik: Sidebar minimalis, collapsible (ciut/lebar), hover expand, submenu bertingkat, dan pengelompokan menu rapi.

2. **Responsive Sidebar Dark / Light (Bedimcode)**  
   - GitHub: [https://github.com/bedimcode/responsive-sidebar-dark-light](https://github.com/bedimcode/responsive-sidebar-dark-light)  
   - Karakteristik: Transisi halus toggle dark/light theme, layout drawer responsif mobile, ikon SVG clean, tidak memakan ruang vertikal atas (layar terasa luas dan tidak sesak).

3. **Sidebar Menu Navigation (Bedimcode)**  
   - GitHub: [https://github.com/bedimcode/Sidebar-menu-navigation](https://github.com/bedimcode/Sidebar-menu-navigation)  
   - Karakteristik: Active pill indicator, tooltip saat sidebar di-collapse, navigasi profil & logout di bagian bawah (footer sidebar), badge notifikasi/status.

---

## 🎯 Tujuan Redesain UI Mendatang
- **Eliminasi Sesak Vertikal**: Menghilangkan tumpukan header atas yang tebal agar ruang kerja input naskah, studio audio, dan visualizer memiliki ruang vertikal maksimal.
- **Akses Cepat 1-Klik**: Menempatkan menu Studio, Mode ILM, Laboratorium Suara, Pusat Manajemen Akun & Audit, serta Pengaturan Kunci API pada sidebar samping kiri yang dapat diciutkan (*collapsible*).
- **Pengalaman iPad & Tablet yang Luwes**: Saat dibuka di iPad/tablet atau layar sentuh, sidebar dapat disembunyikan menjadi drawer hamburger sehingga ruang kreasi audio 100% fokus.
